# Interface language

This fork opens the web and desktop interface in Simplified Chinese. Choose
**Settings → Appearance → Interface → Language** to switch between **简体中文**
and **English**. The choice is saved on this client and applies without reloading
the app.

Provider and model names, file paths, keyboard shortcuts, conversation content,
and original provider error messages keep their original text. Native operating
system dialogs follow the operating system's language. The native mobile app is
not localized by this renderer change.

This build uses Orchestrator V2. Connect it to a V2 server; V1 servers require an
upgrade before this client can use them. See [Updating T3 Code](./updating.md).
