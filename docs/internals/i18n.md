# i18n 约定

Web 与 Desktop renderer 共用 `packages/shared/src/i18n/` 词典。覆盖 `apps/web` 的用户可见文案，包括设置、聊天、侧栏、拉取请求、对话框、提示、空状态和无障碍标签。移动端原生界面和文档翻译暂不在范围内。HarmonyOS 的 ArkWeb 客户端直接使用 Web 文案。

## 词典与调用

`en.ts` 定义全部键，并推导 `MessageKey`。`zh-CN.ts` 提供中文翻译。`index.test.ts` 检查两种语言的键和插值占位符一致。运行时保留“当前语言 → 英文 → 键名”的回退，保证未知文案可显示。

组件通过 `apps/web/src/hooks/useI18n.ts` 读取 `{ t, locale }`。翻译函数随语言变化，React Compiler 和 `useMemo` 才能正确更新缓存。模块级选项表保存键名，在渲染时翻译；后台回调和非 React 代码可以调用 `i18n.t()`，避免在模块初始化时缓存译文。

```tsx
const { t } = useI18n();
return <button aria-label={t("chat.sendMessage")}>{t("action.continue")}</button>;
```

插值使用 `t("sidebar.showMore", { count: 3 })` 和 `{count}`。参数仅支持字符串与数字。数量文案使用 `{count}` 模板；句中 JSX 使用前缀、后缀或完整语义片段，避免把 ReactNode 传入插值。

共享动作使用 `action.*`，状态使用 `common.*`，其余按界面域命名。Desktop 主进程使用 `desktop.*`。新增键同时提供两种译文，并优先复用已有键。设置搜索保留英文别名，使两种语言都能找到同一设置。

## 术语

| English         | 中文         |
| --------------- | ------------ |
| thread          | 会话         |
| project         | 项目         |
| provider        | 提供商       |
| worktree        | 工作树       |
| snapshot        | 快照         |
| pull request    | 拉取请求、PR |
| archive、settle | 归档         |
| keybinding      | 快捷键       |
| plan            | 方案         |
| skill           | 技能         |
| composer        | 输入框       |
| approval        | 审批         |
| checkpoint      | 检查点       |
| draft           | 草稿         |

中文使用全角标点。按钮标签不加句号，界面加载提示使用单字符 `…`。品牌、提供商名称、协议名、快捷键标签、Git 引用、路径、URL、模型 ID 和程序标识符保留原文。日志、原始 `error.message`、写入数据库的种子内容和服务端确认消息保留来源文本。

## 语言切换与打包

默认语言为 `zh-CN`。用户在“设置 → 外观 → 界面”选择语言。`LanguageSync` 将客户端设置同步到全局词典和页面 `lang` 属性。断言英文文案的测试应在 `beforeAll` 固定为 `en`，结束后恢复原语言；切换行为另行验证。

词典是编译期静态链接的 TypeScript 模块，随 Web 和 Electron bundle 分发。开发与生产构建都无需额外下载语言资源。
